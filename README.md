# منصة الاختبارات المهنية

نسخة جديدة مستوحاة من مشروع **muhannad** القديم، لكن بهيكل أسهل للتوسّع.

## الموجود حاليًا
- اختبار PMP
- اختبار CME1
- حفظ تلقائي للتقدم في المتصفح
- تصحيح ونتيجة نهائية
- حفظ أفضل نتيجة لكل اختبار
- تصميم عربي RTL ومتجاوب للجوال
- إضافة اختبارات جديدة من ملف واحد فقط

## إضافة اختبار جديد
افتح `data.js` وأضف عنصرًا جديدًا داخل `window.EXAMS`.

```js
{
  id: "example",
  title: "اختبار جديد",
  subtitle: "وصف الاختبار",
  badge: "التصنيف",
  questions: []
}
```

## إضافة سؤال
داخل `questions`:

```js
{
  n: 1,
  text: "نص السؤال",
  options: [
    { key: "أ", text: "الخيار الأول" },
    { key: "ب", text: "الخيار الثاني" },
    { key: "ج", text: "الخيار الثالث" },
    { key: "د", text: "الخيار الرابع" }
  ],
  answer: "أ"
}
```

## النشر
المشروع Static ولا يحتاج قاعدة بيانات أو خادم. يمكن رفعه مباشرة على GitHub Pages أو Vercel.
